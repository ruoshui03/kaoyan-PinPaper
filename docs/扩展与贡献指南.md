# 题库扩展 / 答案解析 / 去中心化共享中心

面向贡献者：怎么加题库、怎么补答案解析、怎么在不碰版权红线的前提下共享答案。
所有能力都是**可选的**——文件缺失时特性静默不启用，不会让现有部署挂掉。

---

## 1. 加一本新题库（不再需要改代码）

### 1.0 有现成文件？先跑导入器

本机题库导入器会把 JSON / CSV / Markdown（单个文件或整个目录）直接转成标准包并注册：

```bash
# 先看解析结果（不落盘）
python tools/import_bank.py --from ./我的题库.csv --book-key 660 --subject 数学一 --dry-run

# 正式导入并注册
python tools/import_bank.py --from ./题库文件夹 --book-key 660 --name "李永乐660" \
    --subject 数学一 --dir 660数学一 --register
```

认这些列名（中英文、别名都行）：`id/题号`、`stem/题干`、`A/B/C/D` 或 `options/选项`、
`answer/答案`、`solution/解析`、`chapter/章节`、`type/题型`、`difficulty/难度`、`tags/标签`。
缺的列会兜底：题型按内容判定、难度默认综合题、章节归"未分类章节"、题号自动生成。

⚠ **CSV 题干里若有半角逗号，必须加英文双引号**，否则整行列会错位且不会报错。
导入器会统计「题型靠内容推测」的条目数并提示，看到这个告警先去查引号。

导入完成建议自检：`python tools/test_import_bank.py`（覆盖列名映射 → 落盘 → 注册 → 引擎可读）。

### 1.1 手工整理时的目录结构

1. 把目录放进 `题库资料/`，内部结构二选一：

   - **自包含（推荐，第三方题库统一用它）**
     ```
     题库资料/660数学一/
     ├── metadata/*.json      # 每题一条，含 id/stem/options/chapter/question_type/difficulty/tags
     └── problems/images/     # 可选，题图；![xx](images/a.jpg) 会自动内联 base64
     ```
     单条示例：
     ```json
     {
       "id": "第1章-选-01",
       "book": "660",
       "chapter": "第一章 函数、极限、连续",
       "question_type": "选择题",
       "difficulty": "基础题",
       "tags": ["高频经典"],
       "stem": "设 $f(x)=...$，则（　）",
       "options": ["A. ...", "B. ...", "C. ...", "D. ..."],
       "answer": "",
       "solution": ""
     }
     ```
   - **题面/元数据分离（880 专用布局）**：`metadata/*.json` + `problems/*.md`

2. 在 `题库资料/books.json` 加一条：

   ```json
   {
     "key": "660", "name": "李永乐《660》", "order": 10,
     "layout": "self_contained", "enabled": true,
     "subjects": ["数学一", "数学二", "数学三"],
     "dirs": {"数学一": "660数学一", "数学二": "660数学二", "数学三": "660数学三"}
   }
   ```

   **红线：`order` 必须 ≥ 10**（排在内置三本之后）。题号在 URL 位图里是按加载顺序定位的，
   新书插到前面会让用户已收藏的旧链接失效。清单里已放了一条 `enabled: false` 的示例。

加完直接 `streamlit run app.py` 或 `python server.py` 即可，UI 的书籍多选框会自动出现新书。

## 2. 章节名对不上？用别名表

张宇《1000题》按书内细分章组织（高数 18 章 / 线代 9 章 / 概率 9 章），和考纲 23 章不同名。
混在一起曾导致章节下拉出现 77 个"章节"、覆盖率统计失真、按考纲章筛选时 1000题 抽不到。

归一化分三级兜底（`core/chapter_map.py`）：

1. `题库资料/章节别名表.json`（人工维护，键为 `分册|章节名` 或裸章节名）
2. 关键词规则（domain + 章节名关键词 → 考纲章）
3. 都落空则保留原名

效果：数一章节 77 → 24（23 考纲章 + 综合测试卷），数二 49 → 13，数三 72 → 23。
**只改 `chapter`，不改题号**，所以旧链接不受影响。

补映射只需在别名表加一行，例如：

```json
"数学一": { "线代|测试卷一": "综合测试卷", "高数|第0章 零基础": "第一章 函数、极限、连续" }
```

## 3. 答案 / 解析：去中心化共享中心

题库自带的答案与解析目前为空（数一/二/三合计 7617 题）。这块内容由使用者产出，
因此做成**用户授权制 + 可离线传播**的贡献机制（`core/contribution.py`）。

### 数据放哪

```
solutions/<book>/<科目>/*.json | *.csv | *.md      # 本地答案库，加载时自动回填
solutions/_outbox/*.kpp.json                        # 导出的待分享贡献包
solutions/_inbox/                                   # 别人给你的包，放进来即可导入
solutions/consent.json                              # 共享授权开关（默认关闭）
```

支持三种填写格式：

- **Markdown**（手填最方便）
  ```markdown
  ## 01-基础-选-01
  【答案】C
  【解析】先对两端求导，再由单调性…
  ```
- **CSV**：`id,answer,solution`
- **JSON**：`{"book":"880","subject":"数学一","items":[{"id":"...","answer":"C","solution":"..."}]}`

### 命令

```bash
python tools/solutions_hub.py status                     # 本地答案库与授权状态
python tools/solutions_hub.py consent --share --author 昵称
python tools/solutions_hub.py template --book 880 --subject 数学一 --limit 200
python tools/solutions_hub.py import <文件|URL|IPFS CID> --book 880 --subject 数学一
python tools/solutions_hub.py export --book 880 --subject 数学一 --author 昵称
python tools/solutions_hub.py push-git --remote git@github.com:你的fork.git
```

### 界面

Streamlit 侧边栏「🤝 答案 / 解析共享中心」：授权开关、署名、待填模板下载、
导入他人包（拖拽上传）、导出自己的贡献包。Web 端对应 `/api/solutions/*`。

### 授权与红线

- **默认全关**：不勾选授权，导出/推送一律拒绝（API 返回 403），不会有任何数据离开本机。
- **不内置远程地址**：没有任何默认订阅源、没有遥测。URL / IPFS CID / Git remote 必须由用户自己给。
- **导入先校验题号**：题号不在本地题库里的条目直接丢弃并计数，垃圾数据进不来。
- **可选签名**：`--secret` 用 HMAC-SHA256 给 `items` 签名，导入时校验，防止包被篡改。
- **冲突策略**：`remote`（以导入为准，默认）/ `local`（保留本地）/ `longest`（取更长解析）。
- **版权**：包里带 `license` 与 `author` 字段，导入时展示来源；题库素材版权归原作者，
  共享的是**你自己写的解析**，不要把题面整段塞进包里。

## 4. 提交前自查

```bash
python tools/validate_bank.py                 # 三科体检（空题干/选项数/公式定界/缺图/答案覆盖率）
python tools/validate_bank.py --strict        # CI 用：有硬错误就非零退出
python -m pytest -q                           # 全量回归（含新增的 7 条扩展用例）
```
