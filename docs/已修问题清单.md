## 兼容性红线

以上改动中，3、4 只改 `chapter` / `options`，**不动题号与加载顺序**；
新增题库只追加不插队（`order >= 10`），因此：

- `canonical_ids()` 顺序不变 → 用户收藏的旧 URL 位图不失效（已有 `tests/test_paper_code.py` 锁住）
- 回归：`python -m pytest -q --basetemp=.pytest_tmp` → **72 passed**（原 58 + 第一轮 7 + 第二轮 5 + 2）
  - Windows 沙箱下系统 temp 不可写（`PermissionError: [WinError 5]`），必须指定 `--basetemp`
- 判分闭环另有端到端脚本：`python scratch/e2e_wrong_loop.py`
  （起临时服务 8932 → 生成卷 → 导入答案包 → 两次交卷，校验 `markedWrong` / `masteredCount`；跑完自动清理测试答案包）
